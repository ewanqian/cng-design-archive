# 中国国家地理酒店 · 设计档案

设计团队的空间数字归档与展示项目。公开版包含公共区域预览、展项介绍及官方访问入口；内部展览影像与生产素材不进入公开仓库。

## 维护

- `tour.json`：空间、展项文案、访问范围与全景视点。
- `assets/`：经筛选的公开素材。
- `models/`：当前仅有大堂局部 Mesh。
- `vendor/`：第三方组件及许可证。
- `docs/`：立项、来源与制作记录。

发布 main 分支到 GitHub Pages。内部资源需要独立鉴权存储，不能靠前端隐藏。

品牌、空间设计、图像与展项版权归原权利人；本站不授予素材或设计的商用许可。第三方组件各自遵循附带许可证。
